# Landlord testimonial drafts

Twelve drafts for landlords who have agreed to give a reference but asked us to word it. Each is written in the first person, in plain British English, and describes one kind of landlord. Send each landlord the one that fits, ask them to change anything that is not true for them, and get a reply saying "approved" before it goes on the site. Fill the square brackets before sending. Nothing in a bracket is a fact yet.

Where a testimonial is used on the site it will show the landlord's first name and initial, the area, and the type of property, for example "Sarah M., two flats in Leyton". Full names only with written permission.
